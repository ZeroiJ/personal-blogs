## Variant: Editorial Reader

### Design stance
Calm magazine for long reads — generous air, serif headlines.
### Key choices
- Layout: 1120px home with featured split + 3-col cards; article 680px + sticky TOC
- Typography: Inter UI, Newsreader serif headlines, JetBrains Mono meta
- Color: warm paper #FDFDFB, brick accent #B4431F, dark variant
- Interaction: tag filter, reading progress bar, TOC highlight
### Trade-offs
- Strong at: featured builds pop, long articles comfortable
- Weak at: heaviest CSS, needs good cover discipline or looks empty
### Best for
- If you want portfolio visitors to actually finish articles.

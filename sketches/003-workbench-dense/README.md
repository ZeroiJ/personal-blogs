## Variant: Workbench Dense

### Design stance
Tool, not magazine — sidebar + filterable log.
### Key choices
- Layout: 280px sidebar (status, nav, search, type filters) + dense 3-col list rows
- Typography: system sans titles 14.5px, mono everywhere else
- Color: dark-first #0E0E0C / green #7DFF9E, light toggle; restrained terminal
- Interaction: live search + BUILD/EXP/NOTE filter, home↔article
### Trade-offs
- Strong at: scanning 30+ posts, separates builds vs notes clearly
- Weak at: can feel cold; long-form reading less inviting
### Best for
- Experiment log / lab notebook vibe, frequent short posts.

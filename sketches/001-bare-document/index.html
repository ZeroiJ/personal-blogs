Tiny KV store in Go with mmap

2026-09-14 · 8 min · go · discuss on GitHub

I wanted to understand LSM vs B-tree tradeoffs, so I built the dumbest durable KV I could: append-only log + in-memory index + mmap reads. ~300 lines.

The log format

Each record is [keyLen|valLen|key|value|crc]. On open we scan once and rebuild the offset map. Writes are O(1), reads are one seek.

// pseudo — index rebuild
for off := 0; off < size; {
  k,v,n := readRecord(mmap[off:])
  index[k] = off
  off += n
}

Takeaway: for <100k keys this is embarrassingly fine. Compaction is where it gets real — that's part 2.
